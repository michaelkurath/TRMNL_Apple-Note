# TRMNL Apple Note

Send any Apple Note to your TRMNL.

Download and import the [Apple Note shortcut](https://www.icloud.com/shortcuts/f9cb583e81af4946a0cec64ebd0fea49) on your iPhone, iPad, or macOS device. You will need to enter the UUID of this plugin instance during the initial setup. Then you can send any Apple Note to your TRMNL by invoking the shortcut from the Share Sheet.
